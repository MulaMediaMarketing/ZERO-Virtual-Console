# ZERO Player Phase Acceptance Matrix

All phases are active as tracked work. Phase 1 is the implementation gate for architecture-expanding later phases.

## 1. Production Shell Closure
Exit: no known repo-controlled shell blockers; exact-head Windows Build and CodeQL green; physical UI pass complete.

## 2. Home Experience
Exit: authoritative/local-first hero, Continue Playing, Recently Played, artwork/focus states, controller/mouse/keyboard parity, no fabricated service data.

## 3. Library + Game Detail
Exit: search/filter/sort, installed/available state, launch/resume, metadata, storage/version, repair/uninstall/move/verify actions backed by real authority.

## 4. Content Delivery / CDN
Exit: resumable chunked transfer, verification, staging, retry, rollback, bandwidth/storage handling and real provider integration.

## 5. ZERO ID Online
Exit: real sign-in/create/session/recovery/trusted-device flows, secure token handling, local/offline identity fallback, no synthetic online identity.

## 6. Friends / ZERO Link
Exit: real friends, requests, presence, invites, parties, blocking/privacy and joinability through an authoritative provider.

## 7. Achievements + Profile
Exit: authoritative definition/progress/rarity/score UX, local history separation, profile showcase and privacy-safe social projections.

## 8. Store
Exit: real catalog, product details, pricing, regionalization, editions/DLC/bundles, wishlist/checkout and transaction provider integration.

## 9. Entitlements
Exit: account/device/offline/subscription/DLC entitlement authority, revocation/refund propagation and launch enforcement.

## 10. Cloud Saves
Exit: upload/download, versioning, hashes, conflicts, offline reconciliation, rollback and visible sync state.

## 11. ZERO Cloud Play
Exit: authenticated capacity/session provisioning, region/latency selection, video/audio/input streaming, reconnect/resume and entitlement enforcement.

## 12. Capture
Exit: screenshots, clips, gallery/viewer, trim/delete/export, game association and truthful unsupported-state behavior.

## 13. Devices
Exit: authoritative PC/controller/storage/display/remote-device state with supported calibration/security/rename/disconnect actions.

## 14. Notifications
Exit: one real event model covering downloads, installs, achievements, social, cloud, store, security and errors with actionable/dismissible UX.

## 15. Settings
Exit: production-grade Account, General, Display, Audio, Controller, Downloads, Storage, Cloud, Captures, Notifications, Privacy, Accessibility, About and Diagnostics surfaces.

## 16. Updater
Exit: signed manifest, stable/beta/dev channels, staged/delta updates, signature validation, restart/install rollback and crash-safe recovery.

## 17. Security Hardening
Exit: Authenticode, package trust/signature checks, secure storage/transport, parser/path hardening, least privilege, SBOM/dependency scanning and no known release-blocking findings.

## 18. Physical Windows Qualification
Exit: exact-SHA Windows 11 hardware matrix passes display/DPI, controller, sleep/resume, offline/network failure, storage failure, restart and foreground-recovery journeys.

## 19. PR #72 Closure
Exit: current with main, all required checks green, review threads resolved, required approval obtained, merge gates satisfied.

## 20. Signed Production Release
Exit: exact qualified main SHA, production signing, Authenticode verification, final signed E2E pass and production bundle publication.

## Global rule
No phase may satisfy acceptance using fake backend/catalog/social/cloud/payment/device/identity state. Unsupported services remain fail-closed and visibly unavailable until authoritative providers exist.
